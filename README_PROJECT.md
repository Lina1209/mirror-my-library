# Моя библиотека — ©Mirror

Самостоятельная клиентская веб-читалка для личной библиотеки. Проект не меняет существующий README.md в GitHub-репозитории: этот файл имеет отдельное имя и входит только в ZIP.

## Что включено
- Импорт FB2, FB2.ZIP, EPUB, PDF, TXT и HTML.
- Локальное хранение оригинальных файлов в IndexedDB браузера.
- Чтение FB2, EPUB, PDF, TXT и HTML.
- Сохранение позиции чтения, базовые закладки и избранное.
- Поиск по названию/автору, фильтры библиотеки, удаление и скачивание оригинала.
- Адаптивный интерфейс и базовая PWA-оболочка.

## Запуск
1. Распакуйте архив.
2. Откройте папку проекта в редакторе кода.
3. Запустите через локальный HTTP-сервер (например, `python -m http.server 8000`).
4. Откройте `http://localhost:8000`.

Для EPUB/PDF используются внешние библиотеки с CDN, поэтому при первом запуске и чтении этих форматов нужен интернет. Service worker кэширует локальные файлы приложения, но не гарантирует офлайн-загрузку CDN-зависимостей.

## Важно перед публикацией
- Эта версия — стартовая рабочая основа, а не готовая многопользовательская Wix-система.
- IndexedDB хранит книги только в браузере и на устройстве пользователя; очистка данных браузера может удалить библиотеку. Резервное копирование/синхронизация между устройствами ещё не реализованы.
- FB2 отображается как текстовая разметка; встроенные изображения FB2 пока показываются маркером, а не извлекаются.
- HTML проходит базовую очистку от скриптов и опасных встроенных элементов; перед публичным развёртыванием нужна отдельная проверка безопасности.
- Для настоящих аккаунтов, облачной синхронизации, приватных прав доступа и прогресса между устройствами требуется серверная авторизация и серверная проверка userId. Не передавайте доверие клиентскому userId.
- Лицензия проекта намеренно не добавлена: её следует выбрать отдельно до публикации.
- Существующий `README.md` репозитория не входит в этот проектный ZIP и не заменяется.

## Структура
- `index.html` — интерфейс
- `css/styles.css` — оформление
- `js/app.js` — логика библиотеки и читалки
- `js/db.js` — IndexedDB
- `js/parsers.js` — обработка метаданных и FB2/HTML
- `service-worker.js` — базовое кэширование приложения
- `manifest.webmanifest` — PWA-манифест
